// Architecture

5 Defense Layers.
Zero Guessing.

Every command must pass 5 independent checkpoints before touching the DOM. No shortcuts. No AI inference without hard evidence.

🔥
Intent Firewall
Blocks vague commands ("optimize", "clean", "guess") at the door. Outputs structured intent templates instead of silent rejection.
Syscall Filter
🧠
Pattern Immunity Engine
5-component Context Hash (URL + Selector + Parent + Siblings + Intent). Diff 1-2/5 = SUSPECT. Diff 3+/5 = LEAK. Prevents cross-context hallucination.
Anti-Hallucination
⚡
Two-Phase Commit
Phase 1: Plan only — zero DOM touch. Phase 2: Execute once, verify immediately. Execution reentry: strictly forbidden. Narrowing max 2 parent levels.
Transaction Model
🛡️
Atomic Rollback + Post-Validation
On verification failure: instant restore from snapshot. Post-rollback runs all 3 static guards to confirm clean DOM. Decay formula: score = max(0, score − 2).
Kernel Panic Safe
📋
Forensic Audit Trail
Every task logs: dom_hash_before/after, node count delta, halt_namespace, full DTV snapshot. Max 5 snapshots · <1KB each. Debug any failure without asking the agent.
System Logs
